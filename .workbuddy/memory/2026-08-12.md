# 2026-08-12 工作日志

## 项目分析：teacher-workbench（教学工作台）

### 项目定位
面向大学教育专业教师的**本地优先 PWA 工作台**。日程、教学看板、课程、学生、成绩、资源与工具数据均保存在浏览器本地，可导出备份，支持离线使用。

### 技术栈
- React 19 + TypeScript 6 + Vite 8
- @fluentui/react-components（UI组件库，但大量自定义样式覆盖）
- 纯前端，无后端 API，数据存 localStorage
- PWA：Service Worker + manifest.webmanifest
- 自定义 hash 路由（无第三方路由库）
- 自定义通知系统（notify.ts，pub/sub 模式）

### 代码规模
- TS/TSX：约 4170 行（19 个文件）
- CSS：约 1359 行（19 个文件）
- 最大文件：CalendarPage.tsx（664 行）、TaskBoardPage.tsx（416 行）

### 架构
- `src/data/types.ts`：全部数据类型定义（220 行，WorkbenchData 为顶层类型）
- `src/data/seed.ts`：演示数据
- `src/data/store.ts`：localStorage 读写 + 数据合并/迁移逻辑
- `src/hooks/useWorkbenchStore.ts`：核心状态管理 hook
- `src/App.tsx`：路由 + 布局 + 页面分发
- `src/pages/`：10 个功能页面
- `src/lib/`：日期工具、任务工具、通知系统
- `src/components/`：MajorTag（专业标签）、NotifyHost（通知宿主）

### 10 个功能模块
1. 工作概览（Dashboard）- 今日课程、待办、值班、教学进度
2. 日程与值班（CalendarPage）- 周/月视图，事件管理，值班确认
3. 教学看板（TaskBoardPage）- 四列看板，拖拽，优先级管理
4. 课程与排课（CoursesPage）- 课程档案，周课表，进度推进
5. 学生与作业（StudentsPage）- 花名册，CSV导入，作业发布与批改
6. 教学资源库（ResourcesPage）- 资源索引，收藏
7. 成绩与分析（GradesPage）- 成绩录入，统计分析，CSV导出
8. 热点资讯（NewsPage）- 资讯收藏，已读管理
9. 工具箱（ToolsPage）- 工具收藏与自定义入口
10. 设置与备份（SettingsPage）- 资料编辑，JSON导入导出，重置

### 业务领域
三个专业方向：教育学(edu)、小学教育(pri)、学前教育(pre)
演示角色：李明华副教授，教育学院
学期：2024-2025 学年第二学期

## 闭环改造第一批（结合原型 2026-08-07 设计稿）

### 目标
原型（/Users/yun/WorkBuddy/2026-08-07-16-34-39/teacher-workbench）各模块数据独立；本次按「功能少而闭环」打通核心价值链：排课→日历→作业→批改→学情。

### 改动清单
1. **新增 `src/data/sync.ts`**：派生事件同步层
   - `syncCourseEvents(events, courses, weekStart)`：按课程 sessions 重建日历 course 事件（id 约定 `course-{id}-{day}-{section}`，节次→时间映射 SECTION_TO_START=[0,2,6,8] 对应 08:00/10:00/14:00/16:00）
   - `syncAssignmentDeadlines(events, assignments)`：按作业 due 重建 deadline 事件（id 约定 `deadline-{id}`）
   - 约定：`course-`/`deadline-` 前缀事件为托管事件，用户手动事件（uid 生成 id）一律保留
2. **`src/data/seed.ts`**：种子事件只留非派生事件（值班/会议/巡视/独立截止），课程与作业截止由 sync 层生成（单一数据源）
3. **`src/data/store.ts`**：mergeWithSeed 迁移时先滤掉旧手写 course 事件再按课程/作业重建；旧版 localStorage 迁移分支同样接入 sync
4. **`src/App.tsx`**：课程 onChange → patch courses + syncCourseEvents；作业 onChange → patch assignments + syncAssignmentDeadlines
5. **`src/pages/StudentsPage.tsx`**：
   - 发布作业可选「所属课程」（带出 major、total）
   - 提交情况按作业课程过滤学生（submissionStudents）
   - 批改/取消批改 → 该生 homework 完成数自动更新（闭环C）
   - 侧栏批改进度改用 submissionStudents 计算
6. **`src/students.css`**：补 .assignment-composer select 与 .submission-empty 样式
