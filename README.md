# 教学工作台

面向大学教育专业教师的 **本地优先 PWA 工作台**。日程、教学看板、课程、学生、成绩、资源与工具数据均保存在浏览器本地，可导出备份，支持离线使用。

## 功能

- 工作概览：今日课程、待办、值班与教学进度
- 日程与值班：周/月视图，本地持久化
- 教学看板：四列看板，拖拽推进，状态本地保存
- 课程与排课：课程档案与周课表编辑
- 学生与作业：花名册导入、作业发布与批改
- 教学资源库：本地资源索引与收藏
- 成绩与分析：手动录入成绩、均分统计、CSV 导出
- 热点资讯 / 工具箱：收藏与自定义入口
- 设置与备份：资料编辑、JSON 导出导入、重置演示数据

## 开发

```bash
npm install
npm run dev
```

## 构建与预览

```bash
npm run build
npm run preview
```

构建后用 HTTPS 或 localhost 打开，浏览器可「安装应用」离线使用。

## 数据说明

- 存储键：`teacher-workbench-data-v1`（localStorage）
- 备份：设置页导出 / 导入 JSON
- 数据不会上传到服务器
