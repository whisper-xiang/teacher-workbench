# 教学工作台

面向大学教育专业教师的 **本地优先 PWA 工作台**。日程、教学看板、课程、学生、成绩、资源与工具数据均保存在浏览器本地，可导出备份，支持离线使用。

## 功能

- 工作概览：按真实今天展示课程、待办、值班与教学进度
- 日程与值班：周/月视图，本地持久化
- 教学看板：看板拖拽推进，状态本地保存
- 课程与排课：课程档案、多时段周课表、周教学主题
- 学生与评价：花名册导入、过程性评价、作业批改、总评等级
- 教学资源库：本地资源索引与收藏
- 热点资讯 / 工具箱：教育学预置入口（教育部、知网、学前教育研究等）与教育向 RSS
- 设置与备份：资料编辑、演示日程对齐本周、JSON 导出导入

## 开发

```bash
npm install
npm run dev
```

## 构建与预览

```bash
npm run build
npm run preview
```

构建后用 HTTPS 或 localhost 打开，浏览器可「安装应用」离线使用。

## 产品规划

面向教育学讲师日常场景的改进清单与验收标准见 [docs/prd.md](docs/prd.md)。**P0（M1）、P1（M2）与 P2-2 已落地**。

## 数据说明

- 存储键：`teacher-workbench-data-v1`（localStorage）
- 备份：设置页导出 / 导入 JSON
- 数据不会上传到服务器
