# 03 · Critique / QA

用于审查 diff、截图或当前页面。把设计稿/截图与 DESIGN.md 对照。先贴 `00-system.md`。

```
任务：缺陷优先审查下列 UI（代码和/或截图）。
范围：{{PATHS_OR_ROUTE}}

只报告违反 docs/DESIGN.md 的问题。按严重度排序。每条包含：
- 严重度：blocker / major / minor
- 位置
- 违反的条款（引用 DESIGN.md 章节号，如 §0 NEVER、§2.3、§4、§9）
- 为何伤害「approachable luxury / 单色水彩玻璃」
- 具体改法（token 名或 CSS 属性，不要空话）

审查清单（必须逐项看）：
[ ] 是否出现第二色相或紫/霓虹/饱和红绿
[ ] 玻璃嵌套是否 > 3 层，英雄区是否多包了一张底板
[ ] 非 overview 是否把白字写在风景上
[ ] 是否用了 Inter / emoji 导航 / 未登记图标
[ ] 侧栏收起是否露残字
[ ] 科技气质是否偷换成青霓虹而不是冷苔玻璃
[ ] 动效是否超过 400ms 或循环
[ ] 专业标签是否又变成蓝/青/紫三色

没有问题的项不要写。禁止总结式夸奖。若完全合规，只输出：
COMPLIANT. 然后列 1 个可选的 polish（可忽略）。
```
