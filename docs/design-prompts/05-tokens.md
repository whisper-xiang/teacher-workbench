# 05 · Tokens only

只动色板与 CSS 变量。先贴 `00-system.md`。

```
任务：把视觉 token 收敛到 DESIGN.md §2，应用到 {{FILES}}。

要求：
1. 以 --moss-* / --glass-* / --wash-* 为唯一来源。
2. 删除或弃用平行绿色（旧 --accent 可映射到 --moss-40，不要两套）。
3. 单色：专业色、图表色、日历事件色全部改成苔阶明度差；截止 = #8f5b50。
4. Watercolor wash 只出现在 L0 与卡片极淡径向（≤0.08），不要当按钮底。
5. 输出一张「旧值 → 新 token」对照，然后改 CSS。
6. 不要改布局、文案、JS 逻辑，除非选择器必须跟着 token 走。

若某旧色无法映射到 152°±6°，标成 blocker 并给出最近合法替代，等待确认后再写。
```
